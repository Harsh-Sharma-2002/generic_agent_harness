# Coding skill pack — upstream attribution

The skill notes in this directory are imported from Nous Research's
Hermes Agent repository and are substantially unmodified. Only the YAML
frontmatter was normalized for KernelAI: the canonical `id`, `domain`,
`description` and `related` fields were added, and the upstream `name` and
`description` fields were superseded by them. Upstream `version`, `author`,
`license`, `platforms`, `prerequisites` and `metadata` are preserved, and every
skill body and supporting file is byte-identical to upstream.
