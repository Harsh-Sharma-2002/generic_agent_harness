# Skill Registry

Select the smallest set of domains needed for the Task.

## Domains

### [[skills/coding/DOMAIN|coding]]

Software-development methodology: diagnosing failures, driving implementation with tests, reviewing and simplifying changes, observing a running program, prototyping feasibility, and operating repository or GitHub workflows.

### [[skills/teaching/DOMAIN|teaching]]

Student-facing learning methodology: how a learning interaction is run so that the learner does the cognitive work — retrieving, explaining, being helped gradually, diagnosing errors, calibrating confidence, applying knowledge elsewhere, and performing unaided.

### [[skills/research/DOMAIN|research]]

Retrieving current or external information and turning it into an answer scoped to the Task.

### [[skills/data/DOMAIN|data]]

Answering questions from structured data held in a connected relational database.

## Routing Principle

Choose only domains genuinely required by the Task.

A Task may require multiple domains, but do not load domains speculatively.
